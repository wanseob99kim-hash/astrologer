# 베딕 점성술 (Jyotish)

인도 전통 점성술을 한국 대중 대상으로 만든 무료 운세 서비스입니다.

생년월일만 넣으면 수호 행성(나바그라하)이 나오고, 태어난 시간을 더하면
27개 탄생별(나크샤트라)과 120년 다샤 주기까지 확정됩니다.

## 입력은 한 화면, 결과도 한 화면

생년월일·시간·태어난 곳을 한 번에 받고 결과를 한 페이지에 전부 보여줍니다.
단계를 나누면 화면이 갈리고 이탈이 생겨서, 시간을 선택 항목으로 두는 쪽을 택했습니다.

## 시간을 모르면 어떻게 되나

이 서비스의 설계는 측정 결과에서 나왔습니다.

| 산출물 | 시간을 모를 때 오류율 | 노출 단계 |
|---|---|---|
| 물랑크·바갼크 (수호 행성) | 0% | L0 — 생년월일만 |
| 달 나크샤트라 27종 | 23.0% | L1 — 시간 필요 |
| 다샤 타임라인 | 23.0% | L1 |
| 파다 세분 (108종) | 69.0% | L1 + 시간 정확 입력자 |
| 상승궁(라그나) | 90.3% | 사용 안 함 |

시간을 모르면 나크샤트라가 23% 틀립니다.
그래서 시간 없이 들어온 결과에는 **"확정된 결과가 아닙니다" 배너**를 맨 위에 붙이고,
파다(108종 세분)는 아예 표시하지 않습니다. 90% 틀리는 상승궁도 쓰지 않습니다.

근거: [P2 계산엔진 검증보고서](docs/03-analysis/P2-계산엔진-검증보고서.md)

```

content/    27 나크샤트라 · 9 그라하 · 8 쿠타 데이터와 문안

scripts/    문안 미리보기 · 검토 페이지 생성 · 화면 캡처

```

## 계산 엔진

`@ishubhamx/panchangam-js` (MIT) 를 쓰고, 아야남샤는 **라히리(Chitrapaksha)** 로 고정합니다.

검증은 의존성이 겹치지 않는 `mhah-panchang` 을 독립 대조군으로 두고 수행했습니다.
표본 500건에서 두 구현의 나크샤트라 판정이 **전부 일치**했고,
공개된 차트 자료(간디·모디)와도 일치했습니다.

`sweph` 는 AGPL 이라 상용 웹서비스에 소스공개 의무가 생기므로 채택하지 않았습니다.

## 명령어

배포용 빌드는 기준 주소를 반드시 지정합니다. 지정하지 않으면 canonical 과 og:url 에
`http://localhost:3000` 이 박힙니다. `prebuild` 가 이를 경고합니다.

```bash
SITE_URL=https://내도메인 npm run build
```

```bash
npm run dev               # 개발 서버
npm run build             # 프로덕션 빌드
npm run verify            # 계산 엔진 검증 5종 (나크샤트라·다샤·궁합·시간민감도·양방향평균)
npm run content:validate  # 콘텐츠가 엔진 분류 테이블과 일치하는지 대조
npm run typecheck         # tsc --noEmit
npm run review            # 문안 검토용 HTML 생성
npm run shoot             # 화면 캡처 (서버 실행 중일 때)
```

`content:validate` 가 이 저장소에서 가장 중요한 검사입니다.
화면에 "당신은 데바 기질"이라고 써놓고 점수는 락샤사로 계산하는 사고를 막기 위해,
콘텐츠의 분류값(가나·요니·나디·지배성)을 엔진 내부 테이블과 27종 전부 대조합니다.

## 궁합을 계산하는 방식

아쉬타쿠타 36점을 씁니다. 여덟 항목에 1점부터 8점까지 배점이 정해져 있어
총점이 어떻게 나왔는지 항목별로 확인할 수 있습니다.

전통적으로 이 계산은 남녀 역할을 나눠서 하기 때문에, 누구를 먼저 넣느냐로 점수가 달라집니다
(측정 결과 200쌍 중 173쌍). 성별을 입력받지 않기 위해 **양방향으로 계산해 평균**을 냅니다.
그래서 순서와 무관하고, 점수 끝자리에 0.5가 나오기도 합니다.

## 콘텐츠 구성

벤치마크(태국 점성술)가 요일마다 불상·색·방향·숫자·의식을 붙이듯,
이쪽도 각 유형에 전통 항목을 붙였습니다.

- **아홉 행성**: 신격, 방위, 행운의 수, 비자 만트라(종자 진언), 전통 처방, 상징 기호
- **27 탄생별**: 신격, 상징, 방위, 색, 보석, 행운의 수, 기질(가나), 동물(요니), 기운(나디),
  그리고 다섯 축 성향(재물·일·연애·인연·귀인)

도상은 전부 SVG 로 직접 그렸습니다. 행성 기호 9종과 탄생별 상징 27종입니다.
유니코드 문자로 넣으면 글꼴이 없는 기기에서 네모로 깨지거나 이모지로 치환되고,
이미지 파일로 두면 27장을 따로 받아와야 합니다.

도상 색은 행운색을 그대로 쓰지 않고 잉크 색과 섞습니다.
"심연의 검정"은 어두운 테마에서, "오팔 화이트"는 밝은 테마에서 배경에 묻히기 때문입니다.

27 탄생별은 타로 카드 형식으로 보여줍니다. 벤치마크의 삽화가 그 형식이었고,
화려함의 대부분이 그림 자체가 아니라 '틀'에서 나온다고 봤기 때문입니다.
이중 테두리, 로마 숫자, 아치형 만다라, 해와 달, 밑동의 연꽃, 키워드 배너 —
이 틀은 27장이 공유하고, 카드마다 달라지는 것은 번호·상징·키워드·강조색 넷뿐입니다.

카드는 페이지 테마를 따르지 않고 자기 팔레트를 갖습니다.
밝은 화면에서는 양피지에 금박, 어두운 화면에서는 검붉은 바탕에 금박입니다.
손에 쥐는 물건처럼 보여야 해서입니다.

탄생별 결과의 원형 도표는 장식이 아니라 데이터입니다.
황도를 27등분한 눈금 위에 태어난 순간 달이 있던 실제 황경을 찍습니다.

**다섯 축 성향은 계산 결과가 아닙니다.** 전통 성격 서술을 근거로 작성한 값입니다.

## 현지화 원칙

인도 전통을 그대로 옮기면 한국에서 문제가 되는 지점이 있어 다음을 지킵니다.

- **바르나(Varna) 쿠타는 카스트 기반**입니다. 등급 서열을 노출하지 않고 "결의 층"으로 추상화합니다.
- **도샤를 결혼 반대 근거로 쓰지 않습니다.** 라이브러리 기본 설정에서는 망갈 도샤가 70.3%에게 검출되고,
  점수가 18점 이상인 커플의 27%에 "Mismatch" 판정이 붙습니다. 그 판정 문구는 쓰지 않습니다.
- 전 페이지에 "실제 점술·상담·의료·법률·투자 조언이 아닌, 재미로 즐기는 콘텐츠" 고지를 답니다.

## 문안에 관하여

27종의 분류 데이터는 전통 자료와 계산 엔진 양쪽에서 검증된 값입니다.
성격·연애·재물 해석 문안은 그 상징과 신격을 근거로 새로 쓴 창작물입니다.
