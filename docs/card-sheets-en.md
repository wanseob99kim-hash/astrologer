# English card sheets — what to put on each card

Regenerate the 8 sheets in Gemini with the same style as the Korean ones, but with these English banners.
Top: Roman numeral. Banner: keyword. Under banner: archetype. Save to `art-src-en/`, then `python scripts/crop-card-art.py --src art-src-en --out public/cards-en` (update SHEETS/FULL coordinates first) and `npm run cards:sync`.
